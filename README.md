# UFAvia — сервис поиска и бронирования авиабилетов

Полноценное PHP-приложение с базой данных MySQL. Референс: статический макет
`C:\Users\anime\Desktop\ufavia` переписан на PHP с реальным бэкендом.

## Страницы

- `index.php` — главная: поиск, популярные направления, дешёвые билеты из БД
- `search.php` — результаты поиска с фильтрами (цена, пересадки, авиакомпания, сортировка)
- `flight.php` — карточка рейса: расписание, тариф, багаж
- `login.php` / `register.php` / `logout.php` — авторизация (пароли через `password_hash`)
- `cart.php` — корзина: проверка билета и контактные данные пассажира
- `checkout.php` — оформление: данные пассажира, доп. услуги, способ оплаты
- `success.php` — электронный билет с номером, печать
- `profile.php` — личный кабинет: ближайшая поездка, история заказов, настройки

## База данных

MySQL, схема в `database/schema.sql`, данные — в `database/seed.sql`.

Таблицы:

- `airports` — города и аэропорты
- `airlines` — авиакомпании
- `flights` — рейсы (даты, время, цены, остаток мест)
- `users` — пользователи
- `orders` — заказы (данные пассажира, сумма, статус)

Подключение настраивается в `includes/config.php` (Open Server: root без пароля).

## Запуск

Open Server Panel, домен `ufavia` (папка `C:\OSPanel\domains\ufavia`).

```sql
-- создать базу и наполнить данными
SOURCE database/schema.sql;
SOURCE database/seed.sql;
```

После этого сайт доступен по адресу `http://ufavia/`.

## Сценарий покупки

1. Зарегистрируйтесь или войдите
2. Найдите рейс на `search.php` (фильтры в левой колонке)
3. Нажмите «Выбрать» — рейс сохранится в сессии
4. Заполните контакты в корзине
5. Введите данные пассажира, выберите доп. услуги и оплатите
6. На `success.php` появится электронный билет с номером `UF-XXXXX`
7. Заказ появится в истории в личном кабинете; у рейса уменьшится остаток мест

## Технологии

- PHP 8.1, PDO + prepared statements
- MySQL 8 (utf8mb4)
- сессии для выбранного рейса и авторизации
- верстка и CSS из исходного макета, без изменений
